# チャットツールUI - image-type ブランチ

このブランチには、画像からのデザイン指示によって生成されたチャットツールUIが格納されています。

## 概要

Devinによって作成されたチャットツールの初期画面デザインです。
- **生成方法**: 画像からのデザイン指示
- **対象デバイス**: iPhone 16 Pro（402x874px）
- **言語**: 日本語対応

## 機能

- 設定アイコン（左上）
- 新規チャットタイトル（中央）
- 編集アイコン（右上）
- 中央メッセージ「何をしますか？」
- グラデーション枠の入力フィールド
- 送信ボタン

## 技術スタック

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React Icons

## 開発環境セットアップ

```bash
npm install
npm run dev
```

- `main`: プロジェクト概要とブランチ説明
