# devin_design-UI

このリポジトリには、Devinによって作成されたUIデザインが格納されています。

## ブランチ構成

### `text-type` ブランチ
テキストによるデザイン指示から生成されたチャットツールUIが格納されています。
- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- iPhone 16 Pro サイズ対応（402x874）
- 日本語対応

### `image-type` ブランチ  
画像からのデザイン指示によって生成されたチャットツールUIが格納されています。
- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- iPhone 16 Pro サイズ対応（402x874）
- 日本語対応

## 開発環境

各ブランチで以下のコマンドを実行してください：

```bash
npm install
npm run dev
```

## 技術スタック

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React Icons
